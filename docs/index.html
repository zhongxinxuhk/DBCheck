首次使用

  1. 从下载中心选择平台安装包，或按安装文档部署源码。
  2. 启动服务后访问 http://localhost:5003。
  3. 当前发行说明中的初始账号为 admin，初始密码为 admin123。可在用户中心修改密码。
  4. 添加数据库连接，确认驱动与权限，再选择巡检模板。
  5. 查看结果并生成报告，按需设置定时任务。

常见问题

为什么某些数据库的巡检章节为空？

巡检模板和可采集指标随数据库类型、版本及权限变化。请结合数据库兼容性说明检查驱动和账号权限。

如何选择 Linux 安装包？

x86_64 选择 x64，aarch64 选择 ARM64。v1.0.4 便携包要求 glibc 2.28 及以上，具体依赖以对应发行说明为准。

如何启用 AI 辅助诊断？

在 Web UI 中配置本地 Ollama 或兼容的云 API，并确认模型可用。可结合知识库文档辅助诊断。

升级时需要保留哪些数据？

停止服务并备份整个原目录，保留 data/、数据库密码密钥、账号、任务和自定义规则。详细步骤见对应 Release。
