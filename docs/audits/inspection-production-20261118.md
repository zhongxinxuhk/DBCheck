# 巡检生产安全审计记录

审计日期为 2026-11-18。本次范围包括 Oracle、SQL Server、DM、GBase 8a 的常规巡检、集群节点采集、台账补采和报告交付链路。

## 已修复问题

| 问题 | 修复措施 |
| --- | --- |
| 全量台账补采绕过统一执行保护 | 全量与常规采集均使用元数据来源校验、查询超时、服务端限行与有界取数。全量元数据单查询上限为 100000 行，并保留原有整轮 240 秒、20 MB 预算。 |
| JayDeBeApi 的 PreparedStatement 创建后缺少执行前限制 | 在 prepareStatement 返回前设置查询超时、最大行数、抓取批次和字段大小限制。 |
| 会话限制配置阶段缺少超时守护 | 配置与执行共享单查询时间预算，超时触发取消并终止连接后续查询。 |
| 常规巡检、集群采集与台账补采可重叠访问同一端点 | 共用进程间端点租约，同线程嵌套调用可复用租约，其他执行线程与进程保持互斥。localhost 和回环地址归一。 |
| 仅有单查询预算，整轮可持续施压 | 常规连接整轮 SQL 预算默认 120 秒。集群节点子进程 SQL 预算为 25 秒，父进程保留 35 秒退出边界。 |
| 结果截断后可能标记为完整 | 游标显式保留截断状态，巡检结果与补采结果同步该状态。单字段返回长度上限为 16384，超限记录部分采集。 |
| 正则删除注释会修改字符串中的注释符号 | 注释删除保留字符串和引用标识符内容。 |
| 系统目录前缀校验过宽 | 收紧 SYS 名称匹配，保留明确的系统目录对象，拦截业务对象、申请数据锁的提示和高并行度请求。 |
| Oracle JDBC 连接预检与实际执行选项不一致 | 两条路径均传递 SID、服务名、自定义 JDBC URL、指定驱动版本等选项。 |
| 达梦版本子目录中的 JDBC 驱动无法自动找到 | 递归目录参数传到驱动解析器。未登记驱动时支持从随包版本目录发现，并按版本目录和 JVM 兼容性排序。 |
| GBase 8a 节点查询重选 VC 被只读校验拦截 | 提供受标识符格式、库型与超时限制的 VC 选择操作。任意会话 SQL 仍受统一校验。 |
| GBase 8a 误探测 MySQL 复制与归档状态 | 按 GBase 元数据采集可见节点，避免使用 MySQL 复制命令和 binlog 状态推断 GBase 归档能力。 |
| Oracle/DM 多数据文件导致剩余空间重复累计 | Oracle 改用表空间用量指标与块大小，DM 对已按表空间聚合的剩余空间取单值。 |
| Oracle 临时表空间使用量错误使用已分配块数和固定块大小 | 使用 V$TEMP_SPACE_HEADER 的 bytes_used、bytes_free。 |
| SQL Server 索引使用统计跨库关联 | 增加 database_id = DB_ID() 条件。 |
| 缺失集群证据被推断为单实例 | Oracle 单节点结果结合 cluster_database 参数，DM 空节点与不可采集状态保留待核对。 |

已存储预置模板中的两项统计 SQL 修复采用精确原文匹配迁移，用户修改过的 SQL 和自建模板保留现状。迁移具有幂等回归验证。

## 执行约束

- 常规 SQL 仅访问审核后的系统目录和动态性能视图，拒绝业务表扫描、写入、DDL、统计收集、重建、数据清理及任意过程调用。
- SQL Server 索引物理扫描、无时间边界的错误日志读取继续被拦截，并显示采集缺口。SQL Server 元数据查询设置 MAXDOP 1、低死锁优先级与 1 秒锁等待。
- Oracle 会话禁用并行查询，并为查询加入 NO_PARALLEL。GBase 8a 使用 JDBC 语句超时和取消守护，避免发送不兼容的 MySQL 超时会话参数。
- 亿级业务表的行数、大小和索引信息来源于系统元数据与已有累计统计。精确全表计数和物理页扫描不进入常规执行。
- 只读元数据查询仍有解析、目录访问及取数开销。应用侧超时包含取消请求，最终执行中断取决于数据库及驱动响应。

## 验证范围

- 模块回归包含固定取数上限、模拟十亿行源、超大元数据字段、超时取消、总预算耗尽、同端点互斥、连接选项、历史预置 SQL 幂等迁移及用户修改保护。
- Oracle、SQL Server、DM、GBase 8a 本地 Docker 实例均通过正常巡检子进程入口产出结构完整的 Word 报告。
- 四类实例的补采元数据均通过采集快照生成多 Sheet XLSX，并通过内容 SHA-256 和归档签名校验。
- Oracle RAC、DM DSC 节点采集入口在单实例测试环境可运行，缺失同伴节点与空成员结果保留原有覆盖度边界。
- 本轮环境未提供实际多节点 RAC、Data Guard、Always On、DM DSC/守护或 GBase MPP 拓扑，未进行切换及故障注入验证。
- 本轮未建立真实亿级、十亿级业务数据集。有限返回和不访问业务表的验证属于执行约束验证，生产负载、同版本多节点行为与最小权限账号可见性仍需实际环境验收。
