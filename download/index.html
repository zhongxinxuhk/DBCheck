发行说明 ↗

页面载入后同步 GitHub Releases。若同步不可用，可从 完整发行列表 ↗ 查看最新资产。

解压，然后启动。

  • 01

    下载并校验

    选择系统与架构，使用对应 Release 的 SHA256SUMS.txt 校验下载文件。

  • 02

    启动程序

    Windows 双击 start.bat，Linux 执行 bash start.sh。macOS 历史包请参考发行说明。

  • 03

    打开管理界面

    访问 http://localhost:5003，配置数据源并执行首次巡检。

校验与升级

Linux SHA-256 校验
sha256sum -c SHA256SUMS.txt --ignore-missing

校验文件和安装包需来自同一个版本，置于同一目录后执行。

升级前停止服务并备份整个原目录，保留 data/ 及其中的数据库密码密钥。跨 Windows / Linux 迁移时，按便携包说明复制完整目录。
