    接入并组织数据源

    查看风险与报告

从源码启动
git clone https://github.com/zhongxinxuhk/DBCheck.git
cd DBCheck
python -m venv .venv
# 激活虚拟环境后执行
pip install -r deploy/requirements.txt
python web_ui.py

Python 3.10+。启动后访问 http://localhost:5003。数据库驱动与平台依赖请参考安装文档。
